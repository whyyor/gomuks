# gomuks terminal (whyyor's fork)

A terminal Matrix client for Beeper chats (WhatsApp, Instagram, Telegram),
built on [gomuks](https://github.com/gomuks/gomuks) by Tulir Asokan. This fork
keeps only the terminal client (`tui/`, `cmd/gomuks-terminal`) and the backend
daemon it talks to (`cmd/gomuks`); the browser, desktop and wasm frontends are
removed.

See [FORK.md](FORK.md) for the layout, how to build and install, and what
the fork adds. Licensed under the AGPLv3, see [LICENSE](LICENSE).
